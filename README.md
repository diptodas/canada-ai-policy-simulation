# Canadian Policy Simulation

This project samples synthetic Canadian demographic profiles, creates TinyTroupe
agents, simulates discussion of policy announcements, exports responses, and
visualizes the conversation in canada.ipynb.

## Setup

1. Install dependencies with python -m pip install -r requirements.txt.
2. Add OPENAI_API_KEY=... to openai.env.
3. Open canada.ipynb and run all cells.

Generated caches are stored in cache; Excel results are written to outputs.
